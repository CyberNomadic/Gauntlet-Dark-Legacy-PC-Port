# 1.0.0-alpha.3

## Added

- Experimental online multiplayer through Start > Netplay > Host Game / Join Game, with invitation sharing, character selection, readiness checks, and room settings.
- Iroh networking with direct connections and relay fallback. Build and native-asset compatibility are checked before joining a session.
- Online cutscene skip voting: everyone must request a skip. Offline skipping is unchanged, and pausing online does not pause the other players.
- Guest-local field of view and post-processing settings, plus threaded rendering to keep graphics waits from blocking simulation updates.
- Optional smooth filtering for magnified pickup sprites and MSAA alpha coverage for cutout edges.
- GPLv3 license, with author attribution and third-party notices in release packages.

## Fixed

- Guest presentation of portals, arrival effects, player shadows, and portal departure animations; mouse aiming now accounts for the guest's own view.
- Pojo transformations and the EGG911 cheat no longer overlap the original character or consume a permanent inventory slot. Corrected entrance presentation, repeated firing animations, turbo effects, wing transparency, and attack, injury, and Sumner voice cues.
- Wizard and Sorceress melee attacks use the correct stat scaling.
- Earned familiars and the Phoenix can fire together.
- Crystal collection announcements no longer repeat through duplicate promotion handling.
- Pickup clouds and fruit shadows composite after solid chest geometry instead of hiding the chest behind them.
- Fire Shield flames composite correctly around gates and deferred scenery.
- Garm's death effects respect their native one-shot animation flags.
- Enemy strike effects use the struck enemy's attention point.
- Generator placement checks use the enemy's collision sphere and native floor-probe bounds around walls and changes in elevation.
- CI linting reuses verified clean results between runs.
