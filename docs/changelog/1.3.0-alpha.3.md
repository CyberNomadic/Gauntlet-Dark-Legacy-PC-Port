# 1.3.0-alpha.3

## Added

- Native scene timing reports separate gameplay updates, diagnostic observations, and headless rendering to measure the cost of future rewind work.
- Whole-scene rollback online play uses a one-tick local input buffer and predicts remote input for up to eight ticks instead of waiting for every packet.
- Full native-state agreement checks during play and at campaign transitions stop a diverging session instead of silently continuing.
- Real transport tests cover two, three, and four peers, independent render cadences, and zero-, one-, or two-tick local input buffering.
- Real-transport stress tests add controlled input latency, jitter, loss, reordering, and outages, with measured delay and confirmed recovery reports.
- Opt-in public-relay tests disable direct connections, verify every active relay path, and measure network latency separately from local input response.
- Regression coverage for four-player menu-created rooms, local pause and disconnects, level-to-shop-to-Tower transitions with exactly-once local saves, and visible guest movement before remote input arrives.
- Local enemy-pool rewind tests cover changed inputs, animation and RNG state, queued rewards, and one-to-eight-tick replay without reloading artwork.
- Local player-state and action-pose rewind, with a reusable 16-frame history and four-player replay/performance tests.
- Local rewind for Pojo, earned familiars, and temporary companions, including item changes and projectile attachment poses without reloading their artwork.
- Allocation-free shared-camera history for rewinding marker changes and party framing.
- Native combatant and creature-population rewind, retaining boss child actors and loaded artwork across corrected inputs, deaths, and slot reuse.
- Native boss-encounter rewind for wake timing, legend-item effects, shared animation clocks, and pending defeat notifications.
- Native particle history preserves emission, random state, and fractional animation clocks without copying temporary draw geometry.
- Native effect and projectile rewind preserves reflections, contact cooldowns, queued impacts, morphs, particle tails, and animation clocks while reusing loaded artwork.
- Native prediction tests run two- and four-player scenes with delayed, reordered, and lost inputs, comparing corrected state against an all-actual reference.
- Recorded scene audio reconciles corrected one-shots and persistent loops after replay; secret-level rewards and travel wait for every player's confirmed input.
- Native replay comparisons cover complete enemy and fixture snapshots, including queued damage, loot, hidden timers, and resource lifetimes.
- Headless benchmarks measure full eight-frame corrections with recorded audio in active two- and four-player encounters, plus snapshot-copy costs by subsystem.
- Bounded rollback input delivery retains missing frames until each peer acknowledges them, including recovery after prediction stalls. Native scene tests now exercise the same packet path with loss and reordering.
- Native world rewind comparisons include moving collision, destruction, pickup ownership, queued triggers, animation clocks, and random state.
- Native state digests traverse stored player, projectile, trigger, animation, and particle values, rejecting unknown resource bindings and accounting for unordered secret-coin identities.

## Fixed

- Replaying corrected frames no longer repeats sounds, controller vibration, saves, or unlocks.
- Corrected remote input can be replayed and current local input admitted in the same update, avoiding an unnecessary extra frame of delay.
- Opening a local pause menu clears that player's unsent controls without altering other players' input or previously admitted commands.
- Removed the obsolete online lockstep driver from production; offline input behavior is unchanged.
- Native state hashing caches immutable level definitions without omitting live animation, collision, or gameplay state.
- Native state checks use hardware SHA acceleration on supported x64 processors while retaining an identical portable fallback.
- Repeated platform synchronization reuses unchanged collision geometry during normal play and rollback, preserving exact transform state.
- Online failures retain their original explanation through scene teardown instead of replacing it with a numeric error.
- Windows release builds embed their C/C++ runtime so matching game builds no longer depend on identical Windows runtime DLL versions; packaging checks prevent mixed-runtime releases.
- Clang compatibility of retained state diagnostics and missing-asset skips in native regression tests.
- Native scene diagnostics now cover boss arenas and levels with more than 256 authored particle emitters without changing packet admission limits.
- Queued enemy and projectile sounds retain their source identity after actors or projectiles retire, preventing reused slots from taking over earlier cues.
- Native history reuses texture-cycle storage and avoids copying immutable chest and barrel item catalogs.
- Enemy updates avoid capturing the same pre-update presentation pose twice; gameplay continues to use native tick poses.
- Restoring a companion's animation preserves its interpolation interval, including held frames and Pojo's attachments.
- Generator, projectile, transport, and powerup-ending audio retain stable source identities across corrected frames and reused actor slots.
- Desync checks include hidden player cooldowns and all character progress records; native rotator tests no longer depend on the retired rotator/world restore adapters, which now live outside the production library.
- Native particle comparisons no longer depend on texture allocation order, and item rendering no longer changes the simulation's particle texture bindings.
- Native desync checks include complete generator state, both enemy projectile pools, pending trigger inputs, and queued combat rewards and sounds.
- Rewind resource identities remain stable across independent loads, discarded enemy spawns, generated scenery, and fallback particle textures without reloading artwork.
- A failed native replay session cannot reuse its damaged scene or an earlier session epoch; recovery requires a fresh scene load.
- Remaining standalone legacy scene checkpoint adapters are excluded from the runtime libraries and retained only for regression diagnostics.
- Native rollback pacing accounts for both relay hops and queued progress age, without treating repeated relay reports as fresh peer progress or prematurely idling before the first peer report.
- Native desync checks include full enemy and combatant values, recursive boss parts, hidden placement watches, patrol routes, pending combat events, and captured family texture clocks.
- Placed-enemy rewind no longer carries the legacy prepare/commit restore protocol in the runtime library.
- Native desync checks cover statue wake-up state, all boss-health layers, complete camera smoothing history, hidden scene-control timers and random streams, and shared effect lifetimes and texture clocks.
- Effect resource identities include ordered texture lenders and retained character artwork, without depending on installation paths or rendering cadence.
- Rewinding texture scrolling preserves negative and out-of-range authored starting offsets instead of shifting their animation phase.
- A door bars nobody from the moment its key is spent, as the original's player collision has it, instead of holding the party for half a second of its swing; shots still stop on it until it has opened.
- Dagger Peak's entrance no longer has its generators breeding and its enemies attacking the party before it is in play: the original's early-enemies record only lets the placed enemies the camera sees stand during the start camera, and elsewhere they wait for it to end.
- Shots fly through the fences only the party walks against and stop on floor-flagged barriers, as the original's weapon collision mask has it; the Town's bridge fence and the Forest's many such fences no longer stop weapons.
- The special's darkening reaches secret walls and every other level mesh drawn with baked colour, as the original darkens the whole window, so hidden walls no longer stand out bright.
- A pad on a lift tests the floor its visitor rides rather than a fresh probe beneath the feet, which at a deck's edge could find the landing instead and leave a whole-party lift waiting.
- Sumner walks, throws and casts with the master's stats: his class record resolves to the wizard's and every attribute reads 999, as the original's PlayerUpdateAtts has it, instead of a missing seventeenth record leaving him at the slowest pace with no missile power.
