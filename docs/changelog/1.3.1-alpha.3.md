# 1.3.1-alpha.3

## Added

- A traversal test scenario at Ice Camp's railway tunnel, with regression coverage across character classes and update rates.

## Fixed

- Players getting trapped beside Ice Camp's sloping railroad by collision below their feet.
- Player step climbing, uphill movement, and ledge descent using the wrong floor reference or snapping down prematurely.
- Floor contact at platform edges and while riding descending platforms.
- Ice Camp's runestone lift and rotating pillar overwriting each other's movement transforms.
