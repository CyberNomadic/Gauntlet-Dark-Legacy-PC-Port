# 1.2.0-alpha.3

## Added

- Local input replay for supported movement, ranged attacks, melee, turbo attacks, shields, and potion actions, with authoritative correction.
- Replay checkpoints for player and enemy animation, enemy pools, moving geometry, effects, particles, and texture clocks.
- Coordinated enemy, generator, and enemy-projectile correction with atomic restore and bounded replay.
- Portable random-number state and resource-order-independent enemy corrections.
- Bounded network checkpoints for complete enemy, generator, and enemy-projectile state.
- Predicted weapon and potion flight with release identities that prevent duplicate projectiles after confirmation.
- Input-delay telemetry and a separate-process network harness, including optional Docker network-impairment testing.

## Fixed

- Restored guest gameplay audio and synchronized stage sound playback.
- Corrected guest enemy death presentation and animated effect playback.
- Preserved exact animation blends when correcting and replaying player actions.
- Corrected progression-ceremony camera framing for guests.
- Improved connection failure handling and diagnostics for online rooms.
